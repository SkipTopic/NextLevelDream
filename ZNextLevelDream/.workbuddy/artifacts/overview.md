# ZNextLevel Dream —— 总览

> Godot 4.7 / GDScript 2.0 / 1080P 2D 探索游戏。
> 《梦日记》的"睡梦探索 + 效果收集"×《盗梦空间》的"多层梦境 + 坠落穿越"。
> 核心：**四层梦境**。梦越深，醒来的条件越艰难。

## 梦境结构（核心设定）

| 层 | 名称 | 场景 | 进入方式 | 离开方式 | Q 捏脸 |
| --- | --- | --- | --- | --- | --- |
| 0 | 现实 | 现实·卧室 | 主菜单"开始做梦" | ——（现实无处可醒） | —— |
| 1 | 第一层梦境 | 一层·卧室 / 主通道 / 流星世界 / **深林（5760×1620）** | 现实卧室上床睡觉 | **Q 捏脸醒来**（唯一轻醒出口） | ✅ 有效 |
| 2 | 第二层梦境 | 二层·轨道世界 / 保安室内部 / **大街** / **医院外** / **医院内部** | 一层卧室 **床 + 安眠药** | 轨道/大街的**悬崖跳下** 或 **手枪**（Kick 回一层床边） | ❌ 失效 |
| 3 | 第三层梦境 | **草地**（醒来背靠大树；左端小屋、右端钓鱼人） | 保安室的床 **+ 麻醉剂** | 待设计（手枪可回二层床边） | ❌ 失效 |
| 4 | 第四层梦境 | **海洋**（全是水；走路会浸湿日记本） | 草原小屋的白床（**确认后进入**） | 待设计（手枪可回三层床边） | ❌ 失效 |

**死亡规则**：日记页数归 0 → 玩家死亡，黑屏缓缓浮现"永远沉溺在梦境之中吧"，只能回主菜单重开
（GameOver 结算层监听页数变化；写日记把页数用完同样会触发）。

**第四层海水浸页**：没装备"书籍保护套"时，在海洋里每走 2 步（静止不动不算）湿掉 1 页；
装备书套后免疫。书套来自第三层草原右端的钓鱼人。
**浸水表现**：玩家的精灵挂着浸水 shader（`assets/shaders/water_submerge.gdshader`）——
大腿以下的身体逐渐被水色吞没、越深越透明，水面线带波动和反光亮边；
每损失 1 页，玩家周围会生成 2~3 片**漂在海面上的书页**（无碰撞、随机漂动 + 起伏，
`scripts/FloatingPage.gd`，场上上限 36 片、回收最早的）。

**深度分层（Y 排序）约定**：所有"玩家会在物件之间走动"的场景（各卧室 / 保安室 / 草原小屋 /
医院内外 / 草原 / 深林），根节点与家具/树木容器都要开 `y_sort_enabled`——
物件与玩家按 Y 坐标互相遮挡，不再穿模。流星世界的流星 z_index=20，永远画在玩家上方。

**深林世界**：与轨道世界同宽（5760×1620）。树按"军队列阵"式行距错位稀疏分布
（行距 270 / 列距 430 / 隔行错位半列 + 随机抖动 / 25% 跳过），出生点与传送门保持空旷；
全部树木带树干碰撞；根与 Trees 容器开启 `y_sort_enabled`，树与玩家按 Y 分层不乱挡；
树冠挂风摆 shader（`assets/shaders/tree_sway.gdshader`，底部固定、顶部左右摆，
每棵树独立相位；幅度/速度在 DeepForest 节点检查器里调 `Sway Strength / Sway Speed`）。

**海洋渲染**：海面是 canvas_item shader（`assets/shaders/ocean_water.gdshader`）——
两层错速流动的波浪亮纹 + 远处涌浪明暗呼吸 + 微光闪烁，替代了静态贴图；
波速 / 水色 / 亮纹密度 / 闪烁强度都在 Ocean 场景 Water 节点的材质参数里可调。

**标题页萤火虫**：主菜单 Fireflies 层（`assets/shaders/fireflies.gdshader`）——
18 只光点各自沿叠加圆周路径飞来飞去，灯忽明忽暗；数量（循环上限）/ 速度 / 光晕大小 / 灯色可调。

**撕书动画**：写日记成功（`GameState.diary_written`）时由 `TearPage` 结算层播放——
截取当前画面当作一页纸，中缝毛边裂缝 → 两半撕开 → 全黑 → 缓缓变亮回游戏
（`assets/shaders/tear_page.gdshader`，动画期间场景树暂停）。

**梦层跃迁转场**：所有**梦层数发生变化**的移动（睡觉入梦 / 捏脸醒来 / 跳崖 / 手枪 / 麻醉剂下潜）
走 `DreamTransition` 马赛克转场（`assets/shaders/dream_mosaic.gdshader`）——截取旧画面 → 马赛克块逐渐变大直到全屏
→ 趁全屏马赛克切场景 → 截新画面 → 马赛克还原成新场景；动画期间场景树暂停。
同层内的移动（门 / 传送点 / 医院进出等）仍是 SceneFader 淡入淡出。
回归测试：`tools/test_mosaic.gd`（临时 Autoload 方式运行，见文件头说明）。

**UI 广播约定**：所有场景（含主菜单 / 介绍页）`_ready` 时都要 `GameEvents.scene_entered.emit(...)`——
HUD、虚拟摇杆、背包按钮的"主菜单 / 介绍页隐藏"规则依赖这个事件；漏发就会出现"回到主菜单后 UI 还挂着"的 bug。

二层梦境地图流转：轨道世界 →（白门）保安室内部；（保安室旁）→ **大街**；大街悬崖 = Kick 点；
大街下方 → **医院外**（救护车 = 麻醉剂；底部"回大街"出口）；医院大门 → **医院内部**
（接诊台 / 长椅 / 1/2/3号通道占位 / 两扇门占位 / 随机走动的 NPC）；大街左端 → **回铁轨**。

三层地图：醒来点背靠大树；**左端小屋**（带烟囱）→ 小屋内部（白床确认进四层 + 仪器）；
**右端钓鱼人** → 书籍保护套。

规则总结（沿《盗梦空间》）：

- **现实 → 一层**：睡觉就行。
- **一层 → 二层**：需要安眠药（流星世界可捡）+ 在一层梦里的床上使用。安眠药**不消耗**。
- **二层及更深**：Q 捏脸失效（按了只有"醒不过来"的反馈），回上一层必须靠**强烈刺激**（目前实现：跳悬崖）。
- **床锚点**：每次睡进更深一层时，记录"上一层床边的落点"；醒来 / 坠落回上一层时直接落回那张床边——一层多张床也不会"起来发现自己在别的地方"。

## 道具规则（重要约定）

- 所有道具**全局唯一**：不叠数量、没有"剩余 N 个"的概念。
- 所有道具**永不消耗**：安眠药这类"钥匙"道具使用后仍在背包里。
- 道具定义集中在 `autoload/Backpack.gd` 的 `ITEMS` 表；拾取 = 场景脚本调用 `Backpack.add_item("id")`。
- 道具可带 `usable: true`（背包里显示"**使用**"按钮，如手枪）或 `equippable: true`（显示"装备/卸下"）。
- **逐层介绍**：`data/item_descriptions.json`（物品 id × 梦层 0~4 → 介绍文本），可直接编辑，
  背包每次打开都热加载；某层没写就回退 `ITEMS` 的基础 description。
- **逐层介绍约定（必守）**：**每新建一个物品，必须同时在 `item_descriptions.json` 里加一条**，
  层键写全 `"0"~"4"`，还没想好文案的层先用同一句话占位，之后再逐层改。
  忘了加也不会静默出错——`test_backpack` 会检查"每个 ITEMS 物品都有 JSON 条目"并 FAIL。
- **手枪**：保安室办公桌上拾取。在梦境里"使用"→ 开枪痛醒，回到**上一层入睡的床边**（床锚点）；
  第一层使用 → 醒回现实的床边；现实里使用只会说"太危险了"。
- **电瓶车**：大街上拾取。**装备后移动速度加快**——速度在编辑器里调：
  选中任意场景中的 Player 节点（或 `scenes/player/Player.tscn`）→ 检查器 → `Scooter Speed`（默认 560），
  普通速度对应 `Walk Speed`（默认 320）。
- **麻醉剂**：医院外的救护车上拾取。和安眠药同类的"钥匙"道具：在**第二层**的床上（保安室）使用 → 进入第三层；
  第一层用不了（床边会说危险）；不消耗。
- 背包界面：**B 键**开关。左边格子 = 已收集物品；右上 = 展示图；右下 = 介绍 + 使用/装备按钮。打开时暂停游戏。
- 拾取物约定：捡过之后**隐藏贴图并禁用交互区**（`_refresh_*()` 模式），重进场景/读档都由 `_ready` 同步，避免隐形道具冒提示。

## 控制

| 动作 | 按键 |
| --- | --- |
| 移动 | 方向键 / **虚拟摇杆**（触屏或鼠标拖动屏幕左下角） |
| 调查 / 交互（含"跳下去"） | Z / Space / Enter |
| 捏脸醒来（**仅第一层**） | Q |
| 背包 | B |
| 写日记（存档） | Y 或 HUD"写日记"按钮 |
| 关闭背包 / 弹窗 | Esc |

虚拟摇杆 + 触屏按钮（`scenes/ui/TouchJoystick.tscn`，Autoload）：

- 摇杆（左下角）：通过 `Input.action_press/release` 驱动 move_left/right/up/down，`Player.gd` 零改动；支持模拟量与死区。
- 右下角三键"交互 / 捏脸 / 背包"：按下注入对应的 `InputEventAction`（interact / wake_up / backpack），复用 Player、WakeUp、BackpackUI 既有的 `_unhandled_input` 逻辑；多指防抖（"已按下则忽略"）。
- 显示规则：主菜单/介绍页隐藏、SceneFader 转场期间隐藏、背包打开（场景树暂停）期间隐藏，其余游戏场景常驻。
- 桌面用鼠标即可操作调试；`SHOW_ONLY_ON_TOUCH = true` 可切换为"仅触屏设备显示"（安卓发布建议）。

## 存档（日记 = 唯一存档）

`GameState` 写 `user://diary.save`（JSON，版本 4，兼容读 v2/v3）：

- 场景路径 + 玩家坐标（写日记时实时抓取，"在哪写回到哪"）
- 剩余日记页（15 页上限，现实/梦境书桌可补充）
- 做梦次数
- **梦层 `dream_layer`（0=现实，1~4）**
- **床锚点 `bed_anchors`**（梦层 → 床边场景+坐标）
- **背包 `backpack_items` / `backpack_equipped`**（道具随日记存档，收集后没写日记就退出会丢）
- 主菜单"开始做梦"= `GameState.new_game()`：梦层、锚点、背包、做梦次数、日记页全部归零（存档文件保留到下次写日记覆盖）

## 关键设计决策

- 视口 1920x1080，stretch=canvas_items+expand；`gl_compatibility`；纹理最近邻过滤。
- 碰撞层：world=1 / player=2 / interactable=3。
- 交互探针：玩家朝向前方 96px 的 Area2D，最近的可交互体显示 hint。
- 转场统一走 `SceneFader.change_scene(path, out, in, landing)`；坠落 Kick 用"快出慢进"（0.6s 坠 / 1.5s 睁眼）制造刺激感。
- 梦层切换统一走 `GameState.set_dream_layer()`，`is_dreaming` 自动联动。
- 第二层起场景**不挂 WakeUpComponent**，并在 `_unhandled_input` 里对 Q 给"醒不过来"的台词反馈。
- 背包 UI（BackpackUI 自动加载层）打开时 `get_tree().paused = true`，本身 process_mode=ALWAYS。

## 占位美术

所有 PNG 由 `tools/gen_placeholder_art.py` 生成（确定性输出，`pip install pillow` 后运行）。
替换正式美术时**保持文件名与尺寸一致**即可，场景与碰撞无需改动；详见 `asset_replacement_guide.md`。
