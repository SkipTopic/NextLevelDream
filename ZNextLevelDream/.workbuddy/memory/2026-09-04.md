- 新增 `scripts/LoadingSpinner.gd`：`class_name LoadingSpinner extends Control`，`_draw` 画暗轨道弧 + 高亮弧，`_process` 以 0.5 圈/秒缓慢旋转并 `queue_redraw()`。
- 重写 `autoload/SceneFader.gd`：
  - 三段式时序——淡出（SINE + EASE_IN_OUT，默认 0.85s）→ 全黑保持（默认至少 0.60s，显示 spinner + 文案，期间完成 `change_scene_to_file`）→ 淡入（默认 1.05s）。
  - 载入指示器（VBoxContainer：Spinner 96×96 + Label 30px）挂在 FadeRect 子节点，**自动跟随父级 modulate 淡入淡出**，不用单独做动画。
  - 新增 `loading_text` 公共变量（各场景调用前可改）与 `is_transitioning()` 互斥锁、`get_fade_alpha()` 调试接口。
  - 新增 `black_screen_reached` 信号。
- 各场景转场文案差异化：入睡"沉入梦中……"（1.4/1.2s）、醒来"正在醒来……"（1.0/1.3s）、红门"流星正在落下……"、绿门"树影正在摇晃……"、传送门"回到房间……"/"梦在流动……"、主菜单"开始做梦……"/"翻开日记……"。

### Bug 修复

1. **进入游戏即切场景并退出（用户报告"闪退"）**：上轮截图测试结束后忘了把 `_Screencap` 从 `project.godot` [autoload] 移除，导致每次启动游戏 `_screencap.gd` 都会自动执行：切场景 → 截图 → `get_tree().quit()`，表现就是闪退。修复 = 删掉 autoload 行 + 删除 `tools/_screencap.gd(.uid)` + 清理 `_fade_*.png`。
2. **FadeRect 尺寸 0×0 不覆盖屏幕**：`set_anchors_preset(PRESET_FULL_RECT)` 对直接挂在 CanvasLayer 下的 Control 不可靠（布局首帧未解析），表现为黑幕完全不可见、载入文案跑到左上角。修复 = 直接 `_rect.size = get_viewport().get_visible_rect().size`，并连 `viewport.size_changed` 信号同步。
3. **并发转场**：加 `_transitioning` 互斥锁，上一次没跑完就丢弃新的 `change_scene` 请求（之前按门 + 按 Q 会让两个 tween 抢同一个 modulate.a）。
