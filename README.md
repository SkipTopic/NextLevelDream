# Next Level Dream

> 《梦日记》的睡梦探索 × 《盗梦空间》的多层坠落
> Godot 4.7 / GDScript 2.0 / 1920×1080 2D

睡着入梦，越睡越深。**日记本既是存档，也是命。**

一个可玩到第四层的梦境探索原型：现实卧室的床上闭眼，一层层往下潜；每深一层，回来的路就难一分。

## 四层梦境

| 层 | 场景 | 怎么进去 | 怎么出来 |
|---|---|---|---|
| 0 现实 | 现实·卧室 | 主菜单「开始做梦」 | —— 现实无处可醒 |
| 1 第一层 | 梦境卧室 / 主通道 / 流星世界 / 深林 | 现实床上睡觉 | **Q 捏脸**（唯一轻醒出口） |
| 2 第二层 | 轨道世界 / 保安室 / 大街 / 医院内外 | 一层床上 **+ 安眠药** | 悬崖跳下，或手枪（Kick 回一层床边） |
| 3 第三层 | 草地（醒来背靠大树；左端小屋、右端钓鱼人） | 保安室的床 **+ 麻醉剂** | 手枪可回二层；正式出口待设计 |
| 4 第四层 | 海洋（全是水，走路会浸湿日记本） | 草原小屋的白床（确认后进入） | 手枪可回三层；正式出口待设计 |

**三条铁律：**

1. **第一层之后 Q 就失效了。** 按了只会得到一句「怎么捏都醒不过来」。想回去只能靠强烈刺激——跳崖，或者朝自己开一枪。
2. **日记本 15 页，写一次扣一页。** 页数归零 = 死亡，黑屏浮出「永远沉溺在梦境之中吧」，只能回主菜单重开。
3. **床锚点。** 每次睡进更深一层时会记下「上一层床边的落点」，回来时精确落回那张床边，不会「醒来发现自己在别处」。

## 操作

| 动作 | 按键 |
|---|---|
| 移动 | 方向键 / 触屏虚拟摇杆 |
| 调查 / 交互（含「跳下去」） | Z / Space / Enter |
| 捏脸醒来（仅第一层） | Q |
| 背包 | B |
| 写日记（存档） | Y 或 HUD 上的「写日记」按钮 |
| 关闭背包 / 弹窗 | Esc |

手机上没有键盘也能走完流程：左下角虚拟摇杆 + 右下角「交互 / 捏脸 / 背包」三键，走的是同一套输入动作，`Player.gd` 一行没改。

## 系统

**存档 = 日记。** 写 `user://diary.save`（JSON v4，兼容读 v2/v3）：场景路径、玩家实时坐标、剩余页数、做梦次数、当前梦层、床锚点、背包内容。写日记时会**当场抓一次玩家坐标**，所以「在哪写，读档就回哪」，误差 0px。

**梦层跃迁转场。** 所有改变梦层的移动（入睡 / 捏脸 / 跳崖 / 开枪 / 麻醉剂）走马赛克转场：截当前画面 → 马赛克块放大到铺满 → 趁全屏时切场景 → 截新画面 → 马赛克碎开还原。同层内的移动（开门、进出医院）用普通淡入淡出。

**撕书动画。** 写日记成功时，把当前画面当成一页纸，中缝裂开毛边、两半撕开、全黑，再缓缓亮回来。

**海水浸页。** 第四层整片是海。没装备「书籍保护套」时，每走 2 步就湿掉一页；玩家下半身挂着浸水 shader，越深越透明，每掉一页周围会漂起 2~3 张书页，场上最多 36 片。

**背包。** 道具全局唯一、永不消耗——安眠药是「钥匙」不是「消耗品」。同一个物品在不同梦层有不同介绍（`data/item_descriptions.json`，热加载）。

**场景特效。** 6 个 canvas_item shader：海洋波浪、树木风摆、萤火虫、马赛克转场、撕纸、浸水。

## 美术是占位的

所有 PNG 都由 `tools/gen_placeholder_art.py` 程序生成（45 张，`pip install pillow` 后运行）。

替换正式美术时**保持文件名和尺寸不变**，场景和碰撞体一行都不用改。这也是当初选择程序化生成的原因：先把整条游戏链路跑通，美术后面再换。

## 它是怎么做出来的

全程由 **ZCode（GLM-5.3-Flash）** 在电脑上直接操作完成：自己开编辑器、写 `.tscn`、写 GDScript、跑 headless 回归测试、截图检查画面、改 bug、再跑一遍。人只负责提需求和验收。

过程记录没丢，就放在仓库里：

- `.workbuddy/artifacts/overview.md` — 四层结构、道具规则、场景清单、存档结构、实现状态
- `.workbuddy/memory/2026-09-03.md`、`2026-09-04.md` — 当天做了什么、修了什么 bug
- `.workbuddy/memory/MEMORY.md` — 工程约定（命名层、输入动作、组件化、道具必须补 JSON 的硬规矩）
- `.zcode/plans/` — 四层梦境改造的完整计划书

### 两个真实的 bug

**存档位置不对。** 玩家在场景里走了很远才写日记，读档却回到刚进场景的位置。根因：`save_diary()` 用的是 `_ready()` 时记下的坐标，而 HUD 的 Y 键和按钮从不刷新它。修法是在 `save_diary()` 内部强制调一次 `capture_player_position()`，深度优先找 `Player` 节点抓实时坐标——所有存档入口共用同一个写盘函数，从此不可能不一致。

**启动就闪退。** 上一轮截图测试结束后忘了把 `_Screencap` 从 `project.godot` 的 `[autoload]` 里删掉，于是每次启动都会「切场景 → 截图 → `quit()`」。表现就是双击exe 闪一下就没了。修法：删 autoload 行、删临时脚本、清掉残留截图。
